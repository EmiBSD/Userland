# sbin/boot

Process 1, going down, the console and the terminals.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `init` (sbin/init)
- `reboot` (sbin/reboot)
- `shutdown` (sbin/shutdown)
- `nologin` (sbin/nologin)
- `ttyflags` (sbin/ttyflags)
- `kbd` (sbin/kbd)
- `wsconsctl` (sbin/wsconsctl)
- `ldattach` (sbin/ldattach)
