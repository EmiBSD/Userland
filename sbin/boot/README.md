# sbin/boot

Process 1, going down, the console and the terminals.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`init`](init/) (sbin/init)
- [`reboot`](reboot/) (sbin/reboot)
- [`shutdown`](shutdown/) (sbin/shutdown)
- [`nologin`](nologin/) (sbin/nologin)
- [`ttyflags`](ttyflags/) (sbin/ttyflags)
- [`kbd`](kbd/) (sbin/kbd)
- [`wsconsctl`](wsconsctl/) (sbin/wsconsctl)
- [`ldattach`](ldattach/) (sbin/ldattach)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
