# sbin/storage/mounts

Mounting, and serving file systems over NFS.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `mount` (sbin/mount)
- `umount` (sbin/umount)
- `mount_ffs` (sbin/mount_ffs)
- `mount_ext2fs` (sbin/mount_ext2fs)
- `mount_msdos` (sbin/mount_msdos)
- `mount_cd9660` (sbin/mount_cd9660)
- `mount_nfs` (sbin/mount_nfs)
- `mount_ntfs` (sbin/mount_ntfs)
- `mount_tmpfs` (sbin/mount_tmpfs)
- `mount_udf` (sbin/mount_udf)
- `mount_vnd` (sbin/mount_vnd)
- `mountd` (sbin/mountd)
- `nfsd` (sbin/nfsd)
