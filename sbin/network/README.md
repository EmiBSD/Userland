# sbin/network

Interfaces, routes, the packet filter, address configuration and name resolution.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `ifconfig` (sbin/ifconfig)
- `route` (sbin/route)
- `ping` (sbin/ping)
- `pfctl` (sbin/pfctl)
- `pflogd` (sbin/pflogd)
- `dhcpleased` (sbin/dhcpleased)
- `dhcp6leased` (sbin/dhcp6leased)
- `slaacd` (sbin/slaacd)
- `resolvd` (sbin/resolvd)
- `unwind` (sbin/unwind)
