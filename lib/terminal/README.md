# lib/terminal

Terminal handling and line editing.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`libcurses`](libcurses/) (lib/libcurses) (imported)
- [`libedit`](libedit/) (lib/libedit) (imported)
- [`libform`](libform/) (lib/libform) (imported)
- [`libmenu`](libmenu/) (lib/libmenu) (imported)
- [`libpanel`](libpanel/) (lib/libpanel) (imported)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
