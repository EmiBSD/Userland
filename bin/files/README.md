# bin/files

The basic file operations.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `ls` (bin/ls)
- `cp` (bin/cp)
- `mv` (bin/mv)
- `rm` (bin/rm)
- `ln` (bin/ln)
- `mkdir` (bin/mkdir)
- `rmdir` (bin/rmdir)
- `chmod` (bin/chmod)
- `cat` (bin/cat)
- `dd` (bin/dd)
- `df` (bin/df)
- `pwd` (bin/pwd)
- `pax` (bin/pax)
- `ed` (bin/ed)
