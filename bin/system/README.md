# bin/system

The machine's name, the terminal line, a checksum.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`hostname`](hostname/) (bin/hostname)
- [`domainname`](domainname/) (bin/domainname)
- [`stty`](stty/) (bin/stty)
- [`md5`](md5/) (bin/md5)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
