# bin/processes

Listing, signalling and pacing processes; the shell's primitives.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`ps`](ps/) (bin/ps)
- [`kill`](kill/) (bin/kill)
- [`sleep`](sleep/) (bin/sleep)
- [`sync`](sync/) (bin/sync)
- [`test`](test/) (bin/test)
- [`echo`](echo/) (bin/echo)
- [`expr`](expr/) (bin/expr)
- [`date`](date/) (bin/date)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
