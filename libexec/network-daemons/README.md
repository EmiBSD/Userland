# libexec/network-daemons

Daemons inetd and the RPC services start.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `ftpd` (libexec/ftpd)
- `fingerd` (libexec/fingerd)
- `talkd` (libexec/talkd)
- `comsat` (libexec/comsat)
- `rpc.rquotad` (libexec/rpc.rquotad)
- `rpc.rstatd` (libexec/rpc.rstatd)
- `rpc.rusersd` (libexec/rpc.rusersd)
- `rpc.rwalld` (libexec/rpc.rwalld)
- `snmpd` (libexec/snmpd)
