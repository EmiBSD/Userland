# usr/bin/yp-clients

Querying the YP/NIS directory (its servers are usr/sbin/yp).

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`ypcat`](ypcat/) (usr.bin/ypcat)
- [`ypmatch`](ypmatch/) (usr.bin/ypmatch)
- [`ypwhich`](ypwhich/) (usr.bin/ypwhich)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
