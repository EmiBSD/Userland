# usr/bin/file-tools

Finding, describing and installing files (the basic operations are bin/files).

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`find`](find/) (usr.bin/find)
- [`xargs`](xargs/) (usr.bin/xargs)
- [`file`](file/) (usr.bin/file) (imported)
- [`stat`](stat/) (usr.bin/stat)
- [`du`](du/) (usr.bin/du)
- [`touch`](touch/) (usr.bin/touch)
- [`mktemp`](mktemp/) (usr.bin/mktemp)
- [`readlink`](readlink/) (usr.bin/readlink)
- [`realpath`](realpath/) (usr.bin/realpath)
- [`basename`](basename/) (usr.bin/basename)
- [`dirname`](dirname/) (usr.bin/dirname)
- [`locate`](locate/) (usr.bin/locate)
- [`which`](which/) (usr.bin/which)
- [`what`](what/) (usr.bin/what)
- [`lndir`](lndir/) (usr.bin/lndir)
- [`xinstall`](xinstall/) (usr.bin/xinstall)
- [`compress`](compress/) (usr.bin/compress)
- [`shar`](shar/) (usr.bin/shar)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
