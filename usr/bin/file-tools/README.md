# usr/bin/file-tools

Finding, describing and installing files (the basic operations are bin/files).

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `find` (usr.bin/find)
- `xargs` (usr.bin/xargs)
- `file` (usr.bin/file)
- `stat` (usr.bin/stat)
- `du` (usr.bin/du)
- `touch` (usr.bin/touch)
- `mktemp` (usr.bin/mktemp)
- `readlink` (usr.bin/readlink)
- `realpath` (usr.bin/realpath)
- `basename` (usr.bin/basename)
- `dirname` (usr.bin/dirname)
- `locate` (usr.bin/locate)
- `which` (usr.bin/which)
- `what` (usr.bin/what)
- `lndir` (usr.bin/lndir)
- `xinstall` (usr.bin/xinstall)
- `compress` (usr.bin/compress)
- `shar` (usr.bin/shar)
