# usr/bin/system-info

What machine this is, how it is doing, and small system chores.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`uname`](uname/) (usr.bin/uname)
- [`arch`](arch/) (usr.bin/arch)
- [`pagesize`](pagesize/) (usr.bin/pagesize)
- [`locale`](locale/) (usr.bin/locale)
- [`vmstat`](vmstat/) (usr.bin/vmstat)
- [`systat`](systat/) (usr.bin/systat)
- [`ipcs`](ipcs/) (usr.bin/ipcs)
- [`ipcrm`](ipcrm/) (usr.bin/ipcrm)
- [`pctr`](pctr/) (usr.bin/pctr)
- [`kstat`](kstat/) (usr.bin/kstat)
- [`quota`](quota/) (usr.bin/quota)
- [`logger`](logger/) (usr.bin/logger)
- [`newsyslog`](newsyslog/) (usr.bin/newsyslog)
- [`usbhidaction`](usbhidaction/) (usr.bin/usbhidaction)
- [`usbhidctl`](usbhidctl/) (usr.bin/usbhidctl)
- [`script`](script/) (usr.bin/script)
- [`watch`](watch/) (usr.bin/watch)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
