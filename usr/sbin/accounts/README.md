# usr/sbin/accounts

Creating users and groups, the databases built from them, accounting, tokens (what a user does with their own identity is usr/bin/users).

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `adduser` (usr.sbin/adduser)
- `user` (usr.sbin/user)
- `vipw` (usr.sbin/vipw)
- `chroot` (usr.sbin/chroot)
- `pwd_mkdb` (usr.sbin/pwd_mkdb)
- `dev_mkdb` (usr.sbin/dev_mkdb)
- `kvm_mkdb` (usr.sbin/kvm_mkdb)
- `netgroup_mkdb` (usr.sbin/netgroup_mkdb)
- `ac` (usr.sbin/ac)
- `accton` (usr.sbin/accton)
- `sa` (usr.sbin/sa)
- `tokenadm` (usr.sbin/tokenadm)
- `tokeninit` (usr.sbin/tokeninit)
