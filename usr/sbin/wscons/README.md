# usr/sbin/wscons

Console screens, fonts and the console mouse.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`wsconscfg`](wsconscfg/) (usr.sbin/wsconscfg)
- [`wsfontload`](wsfontload/) (usr.sbin/wsfontload)
- [`wsmoused`](wsmoused/) (usr.sbin/wsmoused)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
