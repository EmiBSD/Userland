# usr/sbin/auth

RADIUS, authpf, wireless authentication and certificate renewal.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`radiusd`](radiusd/) (usr.sbin/radiusd) (imported)
- [`radiusctl`](radiusctl/) (usr.sbin/radiusctl)
- [`authpf`](authpf/) (usr.sbin/authpf)
- [`hostapd`](hostapd/) (usr.sbin/hostapd)
- [`acme-client`](acme-client/) (usr.sbin/acme-client) (imported)
- [`ocspcheck`](ocspcheck/) (usr.sbin/ocspcheck) (imported)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
