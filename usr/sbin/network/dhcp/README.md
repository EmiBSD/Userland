# usr/sbin/network/dhcp

DHCP, DHCPv6 and router advertisements: the servers and the lease controls.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`dhcpd`](dhcpd/) (usr.sbin/dhcpd) (imported)
- [`dhcrelay`](dhcrelay/) (usr.sbin/dhcrelay) (imported)
- [`dhcrelay6`](dhcrelay6/) (usr.sbin/dhcrelay6) (imported)
- [`dhcpleasectl`](dhcpleasectl/) (usr.sbin/dhcpleasectl)
- [`dhcp6leasectl`](dhcp6leasectl/) (usr.sbin/dhcp6leasectl)
- [`rad`](rad/) (usr.sbin/rad)
- [`slaacctl`](slaacctl/) (usr.sbin/slaacctl)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
