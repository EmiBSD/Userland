# usr/sbin/yp

The YP/NIS servers (the clients are usr/bin/yp-clients).

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`ypserv`](ypserv/) (usr.sbin/ypserv)
- [`ypbind`](ypbind/) (usr.sbin/ypbind)
- [`ypldap`](ypldap/) (usr.sbin/ypldap)
- [`yppoll`](yppoll/) (usr.sbin/yppoll)
- [`ypset`](ypset/) (usr.sbin/ypset)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
