# usr/sbin/nfs-rpc

The RPC services and network boot.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- [`portmap`](portmap/) (usr.sbin/portmap)
- [`rpc.bootparamd`](rpc.bootparamd/) (usr.sbin/rpc.bootparamd)
- [`rpc.lockd`](rpc.lockd/) (usr.sbin/rpc.lockd)
- [`rpc.statd`](rpc.statd/) (usr.sbin/rpc.statd)
- [`amd`](amd/) (usr.sbin/amd)
- [`mopd`](mopd/) (usr.sbin/mopd)
- [`rbootd`](rbootd/) (usr.sbin/rbootd)

Each entry is a program directory laid out as `docs/PROGRAM.md` says.
