# etc/base

Users, groups, shells, the protocol tables, device nodes, the file-system skeleton, root's dotfiles, the per-architecture files.

Covers, from OpenBSD's base system at the pin (its path in OpenBSD's `src`):

- `master.passwd` (etc/master.passwd)
- `group` (etc/group)
- `shells` (etc/shells)
- `services` (etc/services)
- `protocols` (etc/protocols)
- `rpc` (etc/rpc)
- `MAKEDEV.mi` (etc/MAKEDEV.mi)
- `MAKEDEV.common` (etc/MAKEDEV.common)
- `MAKEDEV.sub` (etc/MAKEDEV.sub)
- `MAKEDEV.man` (etc/MAKEDEV.man)
- `MAKEDEV.mansub` (etc/MAKEDEV.mansub)
- `mtree` (etc/mtree)
- `skel` (etc/skel)
- `root` (etc/root)
- `motd` (etc/motd)
- `minfree` (etc/minfree)
- `etc.<arch>` (etc/etc.<arch>)
