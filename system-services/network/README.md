# system-services/network

Interfaces, addresses, routes, the packet filter, DHCP and name resolution.

- `ifconfig` (sbin/ifconfig)
- `route` (sbin/route)
- `ping` (sbin/ping)
- `pfctl` (sbin/pfctl)
- `pflogd` (sbin/pflogd)

- `rarpd` (usr.sbin/rarpd)
- `traceroute` (usr.sbin/traceroute)
- `tcpdump` (usr.sbin/tcpdump)
- `tcpdrop` (usr.sbin/tcpdrop)
- `trpt` (usr.sbin/trpt)
- `lldp` (usr.sbin/lldp)
- `lldpd` (usr.sbin/lldpd)
