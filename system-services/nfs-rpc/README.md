# system-services/nfs-rpc

NFS and the RPC services.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `mountd` (sbin/mountd)
- `nfsd` (sbin/nfsd)
- `portmap` (usr.sbin/portmap)
- `rpc.bootparamd` (usr.sbin/rpc.bootparamd)
- `rpc.lockd` (usr.sbin/rpc.lockd)
- `rpc.statd` (usr.sbin/rpc.statd)
- `rpc.rquotad` (libexec/rpc.rquotad)
- `rpc.rstatd` (libexec/rpc.rstatd)
- `rpc.rusersd` (libexec/rpc.rusersd)
- `rpc.rwalld` (libexec/rpc.rwalld)
- `amd` (usr.sbin/amd)
- `mopd` (usr.sbin/mopd)
- `rbootd` (usr.sbin/rbootd)
