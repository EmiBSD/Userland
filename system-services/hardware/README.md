# system-services/hardware

Talking to the kernel about devices: sysctl, dmesg, consoles, buses, power, sensors.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `sysctl` (sbin/sysctl)
- `dmesg` (sbin/dmesg)
- `kbd` (sbin/kbd)
- `wsconsctl` (sbin/wsconsctl)
- `wsconscfg` (usr.sbin/wsconscfg)
- `wsfontload` (usr.sbin/wsfontload)
- `wsmoused` (usr.sbin/wsmoused)
- `ldattach` (sbin/ldattach)
- `pcidump` (usr.sbin/pcidump)
- `usbdevs` (usr.sbin/usbdevs)
- `usbhidaction` (usr.bin/usbhidaction)
- `usbhidctl` (usr.bin/usbhidctl)
- `gpioctl` (usr.sbin/gpioctl)
- `eeprom` (usr.sbin/eeprom)
- `memconfig` (usr.sbin/memconfig)
- `acpidump` (usr.sbin/acpidump)
- `sensorsd` (usr.sbin/sensorsd)
- `apmd` (usr.sbin/apmd)
- `apm` (usr.sbin/apm)
- `hotplugd` (usr.sbin/hotplugd)
