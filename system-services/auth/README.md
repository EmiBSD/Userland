# system-services/auth

Authentication back ends, RADIUS and tokens.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `login_passwd` (libexec/login_passwd)
- `login_chpass` (libexec/login_chpass)
- `login_lchpass` (libexec/login_lchpass)
- `login_ldap` (libexec/login_ldap)
- `login_radius` (libexec/login_radius)
- `login_reject` (libexec/login_reject)
- `login_skey` (libexec/login_skey)
- `login_token` (libexec/login_token)
- `login_yubikey` (libexec/login_yubikey)
- `tokenadm` (usr.sbin/tokenadm)
- `tokeninit` (usr.sbin/tokeninit)
- `radiusd` (usr.sbin/radiusd)
- `radiusctl` (usr.sbin/radiusctl)
- `authpf` (usr.sbin/authpf)
- `security` (libexec/security)
