# development-tools/compiler

The compiler, the linker and the C++ runtime.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `clang` (gnu/usr.bin/clang)
- `libcxx` (gnu/lib/libcxx)
- `libcxxabi` (gnu/lib/libcxxabi)
- `libclang_rt` (gnu/lib/libclang_rt)
- `libcompiler_rt` (gnu/lib/libcompiler_rt)
- `tradcpp` (libexec/tradcpp)
