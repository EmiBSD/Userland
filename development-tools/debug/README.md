Tracing and inspecting running programs and the kernel.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `ktrace` (usr.bin/ktrace)
- `kdump` (usr.bin/kdump)
- `ctfconv` (usr.bin/ctfconv)
- `ctfdump` (usr.bin/ctfdump)
- `btrace` (usr.sbin/btrace)
- `procmap` (usr.sbin/procmap)
- `kgmon` (usr.sbin/kgmon)
