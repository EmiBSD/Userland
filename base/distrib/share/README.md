# distrib/share

/usr/share's own trees: share/mk, the rules every Makefile of the base system includes, and the manuals' shared pages.

Programs of this group:

- `mk` (share/mk)
- `man` (share/man)
- `btrace` (share/btrace)
- `snmp` (share/snmp)
- `tmac` (share/tmac)
- `Makefile` (share/Makefile)
- `Makefile.inc` (share/Makefile.inc)

Inherited: `src/` holds these at their paths in the base system's tree, at the pin of `UPSTREAM.toml`.
