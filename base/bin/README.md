# bin

What must work with only the root partition mounted, linked static: a shell and the means to move files (30).

| Directory | What |
|---|---|
| `shells/` | The shells. |
| `files/` | The basic file operations. |
| `processes/` | Listing, signalling and pacing processes; the shell's primitives. |
| `system/` | The machine's name, the terminal line, a checksum. |
| `tapes/` | Tape and changer control. |

Each entry is a group; each group's README lists its programs.
