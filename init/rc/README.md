# init/rc

The start-up scripts and their control; terminals and login prompts.

Covers, from OpenBSD's base system at the pin (origin directory in OpenBSD's `src`):

- `rc` (etc/rc)
- `rc.conf` (etc/rc.conf)
- `rc.d` (etc/rc.d)
- `netstart` (etc/netstart)
- `daily` (etc/daily)
- `weekly` (etc/weekly)
- `monthly` (etc/monthly)
- `changelist` (etc/changelist)
- `rcctl` (usr.sbin/rcctl)
- `getty` (libexec/getty)
- `gettytab` (etc/gettytab)
- `ttys.pty` (etc/ttys.pty)
- `ttyflags` (sbin/ttyflags)
